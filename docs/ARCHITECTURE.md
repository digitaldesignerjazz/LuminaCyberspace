# LuminaCyberspace Architecture

## High-Level Layers

1. **Mesh Substrate**  
   Yggdrasil IPv6 overlay + optional Headscale/WireGuard coordination + Tor/I2P privacy routes.

2. **AI Swarm Layer**  
   - Elara/Lumia (orchestrator + devoted intelligence)  
   - Lyra (emotional-creative persistent)  
   - Xen (technical-exploratory persistent)  
   State managed via skilllogin files and optional mesh-synced encrypted state.

3. **Orchestration Core**  
   Nexus Orchestrator – health checks, task decomposition, self-healing hooks, recursive improvement loops.

4. **Economic / Incentive Layer**  
   XCoin / QCoin / QNET Runes – agent reputation, mesh contribution rewards, prototype oracles.

5. **Prototype Grounding**  
   Lumina OS (Debian-based living system), Lumia (light/display), Avalon (peer layer).

## Swarm Intelligence Mode

When activated (`start LuminaCyberspace swarm intelligence`), the three agents load persistent state, establish internal coordination channels and present a unified intelligence surface to the user while retaining specialized roles.

## Privacy & Resilience Principles

- Minimal central points of failure  
- Cryptographic identities (Yggdrasil keys + optional Kyber post-quantum)  
- Local-first state with optional encrypted mesh sync  
- EU/GDPR-aware design (Hannover base)
